## Welcome to NFDI4Cat 👋

You can use the [discussion](https://github.com/orgs/nfdi4cat/discussions) function here as a kind of help desk.
We are happy to support you in the use of our tools and look forward to discussing other topics related to research data management in catalysis.
If you prefer a more private or direct contact, you can also reach us via the [contact form](https://nfdi4cat.org/en/contact/) of our homepage.

Besides the software and datamodel repositories here, some outputs of NFDI4Cat have their main development place elsewhere:

* **Adacta** - GitHub: [adacta-rdm/adacta](https://github.com/adacta-rdm/adacta) - A software tool to store research data in a way that is easily understandable and traceable by creating a digital twin of a laboratory setup. A time-accurate record of all components used to measure the catalytic performance of chemically reacting flows is stored.
* **LARASuite** - Gitlab: [LARAsuite/lara](https://gitlab.com/LARAsuite/lara) - LARAsuite is an open-source, next-generation platform for research data management, electronic lab notebooks (ELNs), and laboratory information management (LIMS). It supports the full scientific workflow—from planning and experiment execution to data evaluation and sharing.
* **DCAPT-AP-Plus** - GitHub: [nfdi-de/dcat-ap-plus](https://github.com/nfdi-de/dcat-ap-plus) - A domain-agnostic extension of the DCAT Application Profile. It allow providing domain-specific metadata for the processes and agents involved in the creation of a dataset as well as for the entities or processes the dataset is about. This is a join development of NFDI4Cat and NFDI4Chem.
* **Chem-DCAT-AP** - GitHub: [nfdi-de/chem-dcat-ap](https://github.com/nfdi-de/chem-dcat-ap) - An extension of the DCAT Application Profile PLUS LinkML schema. It is intended to be used by NFDI4Chem & NFDI4Cat as a core that can further be extended in profiles/schemas to provide chemistry specific specific metadata for a dataset.
